Guía Rápida de Comandos Git

Proyecto práctico del curso Git y GitHub - Juan Aguilar Haro.

Comandos Básicos

  • git init: Inicializa un repositorio local.
  • git status: Muestra el estado de los archivos.
  • git add .: Agrega los archivos al área de preparación (staging).
  • git commit -m "mensaje": Guarda una versión en el historial local.
